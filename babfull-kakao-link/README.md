# Babfull KakaoLink CLI

밥풀매니아의 카카오 사용자 정의 템플릿(`138483`)을 로컬에서 검증하는 Node.js 20+ TypeScript PoC입니다. 현재 범위는 공식 카카오 API를 이용한 **나에게 보내기**이며, Supabase·서버 배포·스케줄러는 포함하지 않습니다.

## 실행 준비

1. 카카오 디벨로퍼스에서 카카오 로그인을 활성화합니다.
2. 동의항목 `talk_message`를 설정합니다.
3. REST API 키의 Redirect URI에 `http://127.0.0.1:4399/oauth/callback`을 등록합니다.
4. 템플릿 `138483`의 제목과 본문을 각각 `${month}월 ${day}일 중식 메뉴`, `${menuText}`로 저장합니다.
5. 저장소 상위 `.env` 또는 이 디렉터리 `.env`에 `.env.example`의 값을 설정합니다.

```bash
npm install
npm test
npm run typecheck
npm run dev
```

CLI에서 `1`을 선택하면 발송 내용을 먼저 보여주고 확인을 받은 뒤 브라우저 OAuth를 시작합니다. 토큰은 Git에서 제외된 `.local/kakao-tokens.json`에 권한 `0600`으로 저장되며 로그에는 출력되지 않습니다.

## 로컬 검증 결과

- 템플릿 ID `138483`에 `month`, `day`, `menuText` 세 인자만 전달
- 카카오 메모 API 응답 `result_code=0` 확인
- 카카오톡 나와의 채팅에서 제목과 메뉴가 치환된 FEED 카드 수신 확인
- 포매터·전송 요청·미지원 기능 표시 자동화 테스트 통과

## 채팅방 전송 상태

카카오 공식 API는 일반 단체 채팅방 목록 조회나 임의 단체방 자동 발송을 지원하지 않습니다. `cjh980402/kakao-link` 2.0.1에는 공개 `listRooms()`가 없고, 계정 이메일·비밀번호 로그인 후 비공식 공유 피커의 `/api/talk/chats` 응답을 `send()` 내부에서만 사용합니다. 반환 데이터에서 `title`과 `id`를 사용하지만 이를 외부에 반환하는 인터페이스는 없습니다. 이 방식은 카카오 내부 API 변경, 추가 인증, 계정 보안 및 정책 호환성 위험이 있어 현재 PoC에는 포함하지 않았습니다. 인증 우회나 내부 API 의존 기능을 구현하지 않으며, 별도 기술·정책 검증 전에는 채팅방 전송을 지원한다고 표시하지 않습니다.
